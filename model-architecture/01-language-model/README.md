# 01｜语言模型究竟在学什么

比较均匀、unigram 和 bigram 三个模型，理解条件概率、负对数似然与困惑度。对应文章目前为本地 Review 初稿。

## 运行

从仓库根目录执行：

```bash
python3 model-architecture/01-language-model/experiment.py
```

Python 3 标准库即可；验证环境为 Python 3.12.3。无需安装额外依赖，无需 GPU。数据内置于脚本，采用空格分隔的中文词。

## 实验设置

- 训练集 8 句，验证集 4 句；完整句子不重叠。
- 词表只来自训练集，并包含 `<eos>`、`<unk>`，共 11 个输出候选。
- `<bos>` 只作为上下文，不作为预测目标；`<eos>` 参与计分。
- 加一平滑固定为 alpha=1；统计训练集 32 个、验证集 16 个目标位置。
- 使用自然对数，loss 单位为 nat，PPL=exp(loss)。

## 结果与限制

实际运行输出保存在 [expected-output.txt](expected-output.txt)。验证集困惑度分别为 11.0000、8.9000、5.8130。结果确定，不涉及随机初始化。

脚本检查了训练与验证句子不重叠，以及条件分布归一化。这是手工合成的组合实验；验证句子仍复用了词与局部搭配，不能作为自然语言理解或一般泛化能力的结论。此处“训练”为计数估计，不使用反向传播。
